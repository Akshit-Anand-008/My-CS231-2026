Reference machines for 08_outlab
================================

Every time, speedup and perf count quoted in the problem statement comes from machine A,
unless it says "SL". Your numbers will differ: a different CPU, cache size or compiler changes
them. Compare ratios (base vs fixed, before vs after) on your own machine, not absolute times.
Print your own machine the same way with:  make sysinfo

Per-core cache size = total / instances (e.g. L2 8 MiB over 8 instances = 1 MiB per core).
All runs: built by the makefiles in this folder, pinned with taskset -c 1, nothing else running.
