== B4. Diagnosis ==
hotspot 1: cause = function call overhead because element() is a real call per access at -O0 (43% self)
hotspot 2: cause = not SIMD because neighbouring outputs res[i][j], res[i][j+1] use the same kernel value and
           neighbouring inputs: 2 (SSE2) outputs per instruction are possible
hotspot 3: cause = stride/cache misses (b down a column) and not SIMD
